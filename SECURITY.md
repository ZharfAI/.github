# Reporting a security issue

If you find a vulnerability in Zharfban, zharf.ai or anything else we run, email
**[contact@zharf.ai](mailto:contact@zharf.ai)** with "Security" in the subject.
Please do not open a public issue or post it anywhere else first.

Helpful to include:

- what is affected (a URL, a screen, or an API endpoint),
- the steps that reproduce it,
- what an attacker could read or change because of it.

We read reports in English or Persian, confirm that we received yours, and tell you when it is
fixed. Please give us a reasonable time to fix it before you disclose it, and do not access,
change or delete other people's data while you test.
